# STL Master UI Kit

Изолированная базовая библиотека UI-компонентов для будущей миграции интерфейса STL Master.

На этапе 4 библиотека не подключается к приложению, не меняет маршруты, не использует API и не содержит бизнес-логику.

## Компоненты

### Базовые

- `Button` - кнопка действий. В будущем: Landing, Studio, Admin, Premium.
- `IconButton` - квадратная кнопка с иконкой. В будущем: Studio toolbar, Admin tables, модальные окна.
- `Input` - однострочное поле ввода. В будущем: Admin filters, Premium forms, Studio settings.
- `Textarea` - многострочное поле ввода. В будущем: feedback, support, admin notes.
- `Badge` - компактный статус или метка. В будущем: тарифы, статусы задач, проверки модели.
- `Divider` - визуальный разделитель. В будущем: панели, карточки, таблицы.
- `Loader` - индикатор загрузки. В будущем: обработка модели, запросы API, модальные состояния.
- `Skeleton` - placeholder загрузки. В будущем: история задач, таблицы, карточки.
- `Container` - ограничитель ширины секции. В будущем: Landing и документационные страницы.

### Составные

- `Card` - универсальная карточка. В будущем: Landing cards, Admin summaries, Studio hints.
- `Panel` - каркас боковой или служебной панели. В будущем: Studio inspector, Admin side panels.
- `Section` - секция с номером, подписью, заголовком и описанием. В будущем: Landing.
- `Modal` - только каркас модального окна. В будущем: Premium flow, confirmations, errors.
- `EmptyState` - пустое состояние. В будущем: история задач, заявки, feedback, файлы.
- `StatCard` - карточка статистики. В будущем: Landing stats, Admin dashboard.
- `MetricCard` - карточка технической метрики. В будущем: Compare, Viewer, QA results.
- `HeroCard` - компактная карточка преимущества. В будущем: Hero и промо-блоки.

## Правила

- Компоненты используют только React.
- Компоненты не импортируют существующие проектные компоненты.
- Компоненты не обращаются к backend.
- Компоненты не используют роутер, Context или глобальное состояние.
- Стили находятся только в `frontend/src/ui/styles/`.
- Стили опираются на токены `--stlm-*`, созданные в дизайн-системе.
- `Demo.jsx` является стендом разработки и не подключается к приложению.
