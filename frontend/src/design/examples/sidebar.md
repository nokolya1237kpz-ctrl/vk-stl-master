# Sidebar Example

Источник: `StudioSidebar`, `studioToolsV8`, `adminSidebar`, `adminDashboard.sidebarCollapsed`.

## После восстановления

Sidebar имеет один active state, стабильную ширину, понятные labels/icons и корректный collapsed mode.

## Ограничение

Навигация, права доступа и admin actions не меняются.
