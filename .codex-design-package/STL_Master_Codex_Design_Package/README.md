# STL Master Codex Design Package

Внутри объединены 4 этапа дизайна для передачи Codex.

## Папки

1. `STL_Master_Stage_01_Hero` — Hero Screen + Sticky Header.
2. `STL_Master_Stage_02_Product_Sections` — процесс, соединения, функции, До/После.
3. `STL_Master_Stage_03_Premium_Forms_Footer` — Premium, формы, отзывы, FAQ, footer.
4. `STL_Master_Stage_04_Motion_Final_Polish` — motion system и финальный polish.

## Главный файл

Передавать Codex:

```text
FINAL_CODEX_PROMPT.md
```

## Как давать Codex

Лучше открыть новую сессию Codex, загрузить всю эту папку в проект или положить её в:

```bash
/home/codex/projects/vk-stl-master/design/STL_Master_Codex_Design_Package
```

Затем дать Codex содержимое `FINAL_CODEX_PROMPT.md`.
