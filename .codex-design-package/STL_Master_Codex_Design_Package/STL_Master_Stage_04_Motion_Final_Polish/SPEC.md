# ЭТАП 4 — Motion, Premium UX и финальный полиш

## Цель
Последний этап превращает сайт в продукт уровня SaaS.

### 1. Motion System
- Плавое появление блоков (IntersectionObserver)
- Hover-анимации карточек
- Живые кнопки (градиент, ripple, glow)
- Параллакс hero
- Плавный scroll между секциями
- Sticky header с уменьшением при прокрутке
- Активный пункт меню

### 2. Hero Demo
Показывать цикл операций:
- Repair STL
- Split
- Glue
- Pins
- Magnets
- Lock
- Print Check
Менять статус, прогресс, очередь и превью автоматически.

### 3. 3D Viewer Mockup
Профессиональный интерфейс:
- дерево операций
- свойства справа
- тулбар сверху
- координатная сетка
- XYZ gizmo
- статусная строка

### 4. Финальный Premium UX
- Glassmorphism
- Глубокие тени
- Аккуратные blur
- Радиусы 24–36 px
- Единая система кнопок
- Единые отступы 8px grid

### 5. Performance
- Lazy loading изображений
- SVG вместо тяжёлых элементов
- Без лишних библиотек

### Acceptance
- Header всегда сверху.
- Hero выглядит как реальная программа.
- Все переходы плавные.
- Нет дёрганий.
- Mobile полностью адаптивен.
- Backend не изменяется.
