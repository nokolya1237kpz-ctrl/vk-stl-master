# STL Master: Beta Launch Checklist 1.0

Дата: 2026-06-15

## Решение

Проект можно давать первым закрытым тестировщикам при ограниченном запуске и явном beta-предупреждении.

Текущая оценка готовности: 86/100.

## Проверено

| Область | Статус | Комментарий |
| --- | --- | --- |
| Beta Banner | Готово | Баннер включён через `beta_mode=true`, текст понятный и не перекрывает основной сценарий. |
| Feature Flags | Готово | `surface_recovery=false`, `fix_symmetry=false`, отключённые режимы скрываются на frontend. |
| Feedback | Готово | Отзыв сохраняется JSON-файлом в `/data/results/feedback`. |
| Feedback fields | Готово | Сохраняются `job_id`, `operations`, `rating`, `comment`, `contact`, `timestamp`. |
| Job Info | Готово | UI показывает Job ID, операции, размер исходного STL, итоговый STL и время обработки. |
| Upload errors | Готово | Не-STL и превышение лимита получают понятные ошибки без traceback. |
| Local smoothing without selection | Готово | Frontend показывает “Сначала выберите участок модели.” |
| Orientation without transform | Готово | Worker завершает controlled failure, visible result не создаётся. |
| Downloads | Готово | `final_download_url`, ZIP и файлы из `generated_files` покрыты smoke-тестами. |
| Public Safety | Готово | Технические JSON/manifest скрыты в “Дополнительно”; внутренние пути не выводятся на главный экран. |
| Documentation | Готово | Есть `BETA_TEST_GUIDE.md` и `BETA_READINESS_REPORT.md`. |

## Готово для тестировщиков

- Проверить модель.
- Улучшить модель.
- Удалить AI-артефакты.
- Применить ориентацию.
- Подобрать ориентацию.
- Уменьшить вес.
- Разрезать модель.
- Разрезать под стол.
- Выборочная правка.
- Compare View: до/после, overlay, подсветка изменений и дефектов.
- Скачать итоговый STL, ZIP и отдельные файлы.

## Ограничено

- Публичный beta-лимит загрузки: 100 МБ.
- Не запускать массовые параллельные тесты: текущий сервер рассчитан на последовательную beta-проверку.
- Split со штифтами/пазами требует проверки в слайсере и тестовой печати.
- Local smoothing зависит от плотности mesh и выбранного радиуса.
- AI cleanup удаляет отдельные мусорные островки, но не вырезает наросты, слитые с корпусом.

## Скрыто

- `surface_recovery` скрыта через feature flag, потому что на больших реальных STL часто завершается controlled failure без измеримого результата.
- `fix_symmetry` скрыта через feature flag, потому что симметрия безопасна только для моделей, которые действительно должны быть зеркальными.

## Запрещено рекламировать

- “Автоматически идеально восстановит AI-модель”.
- “Исправит любую STL без ручной проверки”.
- “Гарантирует посадку штифтов/пазов”.
- “Удалит все наросты и дефекты, даже если они слиты с основной геометрией”.
- “Заменяет профессиональный Blender/MeshLab/Open3D workflow”.

## Лимиты для beta

- Публичный beta upload limit: до 100 МБ.
- Абсолютный технический safety hard limit backend: 500 МБ.
- Не больше 20-50 тестировщиков в первой волне.
- Просить пользователей начинать с одного режима обработки за раз.
- Просить скачивать и проверять результат в слайсере перед печатью.

## Что сказать тестировщикам перед запуском

STL Master находится в beta. Он уже умеет анализировать, очищать, ориентировать, разрезать и сравнивать STL, но результат нужно проверять перед печатью. Если модель не изменилась или операция отклонена, это нормальное защитное поведение: сервис не должен ухудшать STL ради видимости результата. После каждой обработки оставьте отзыв прямо в интерфейсе.

## Launch Gate

Перед приглашением тестировщиков выполнить:

```bash
./tests/run_all_smoke_tests.sh
curl -I http://localhost:3000
curl http://localhost:8000/health
./scripts/disk-usage.sh
```

Если smoke-тесты проходят, frontend/backend доступны, а на диске есть минимум 10 ГБ свободного места, закрытый beta-запуск разрешён.
