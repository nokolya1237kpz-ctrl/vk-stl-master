# STL Master: Beta Readiness Report

Дата: 2026-06-14

## Статус

Проект технически готов к закрытому beta-тестированию на ограниченной группе пользователей. Основной pipeline загрузки, очереди, обработки, скачивания ZIP и отдельных файлов стабилизирован smoke-тестами.

Оценка готовности: 78/100.

## Экспериментально

| Функция | Причина |
| --- | --- |
| Surface Recovery | Часто не даёт измеримого прироста score; по умолчанию скрыта feature flag. |
| Fix Symmetry | MVP-симметрия может быть нежелательной для асимметричных моделей. |
| Local Smoothing | Требует ручного выбора области; точность зависит от плотности mesh. |
| Split connectors | Математическая QA не заменяет тестовую печать и проверку посадки. |

## Скрыто по умолчанию

- `surface_recovery`: отключено в `config/features.json`.
- `fix_symmetry`: отключено в `config/features.json` для первой beta-волны.

## Нельзя рекламировать пользователям

- Автоматическое “идеальное” восстановление AI-модели.
- Профессиональный remesh уровня Blender/MeshLab/Open3D с ручной ретопологией.
- Гарантированную печатную посадку штифтов/пазов без проверки в слайсере.
- Удаление наростов, слитых с основной геометрией, без риска изменения формы.
- Автоматическую реконструкцию марки/объекта по STL.

## Safe Limits

- Публичный beta upload limit: 100 МБ.
- Абсолютный технический safety hard limit: 500 МБ.
- Heavy processing soft limit: 300 МБ.
- Heavy operations soft limit: 2 млн треугольников.
- Blender/boolean операции имеют controlled failure и не должны ронять весь job.
- Пользовательский UI не должен показывать traceback или stack trace.

## Beta Risks

| Риск | Приоритет | Что делать |
| --- | --- | --- |
| Нехватка диска после smoke-тестов | Высокий | Регулярно запускать `./scripts/cleanup-test-artifacts.sh 6`. |
| Сложные STL могут уйти в controlled failure | Средний | Показывать понятную причину и просить у пользователя файл. |
| Surface Recovery без видимого эффекта | Средний | Скрыто feature flag до стабилизации. |
| Boolean split на сложной геометрии | Средний | Оставить fallback и честное сообщение. |

## Beta Recommendation

Запускать закрытый тест на 5-10 пользователях с небольшими STL до 100 МБ. Для первых тестов включить только:

- Проверить модель
- Улучшить модель
- Удалить AI-артефакты
- Применить ориентацию
- Разрезать модель
- Выборочная правка
- Сравнение моделей

Surface Recovery оставить выключенной до отдельной стабилизации.

## Изменения по первым отзывам beta

- Добавлено ручное перемещение модели по столу перед сохранением ориентации.
- Добавлены точные повороты по X/Y/Z в градусах.
- Добавлено ручное смещение плоскости разреза по выбранной оси.
- Криволинейный разрез, sculpt-кисть и раскраска модели оставлены в roadmap, чтобы не расширять beta за пределы стабилизированного pipeline.
